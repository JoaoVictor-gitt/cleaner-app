# Images

Place your own photos in this folder using exactly these file names.
While a file is missing, the site shows a styled placeholder instead.

| File                  | Used in                         | Recommended size / ratio      |
|-----------------------|---------------------------------|-------------------------------|
| `hero.jpg`            | Home — hero section             | 1200 × 1000 px (6:5)          |
| `service-regular.jpg` | Services — Regular Cleaning     | 960 × 660 px (16:11)          |
| `service-deep.jpg`    | Services — Deep Cleaning        | 960 × 660 px (16:11)          |
| `service-tenancy.jpg` | Services — End of Tenancy       | 960 × 660 px (16:11)          |
| `service-office.jpg`  | Services — Office Cleaning      | 960 × 660 px (16:11)          |

Tips:
- Use photos you own or are licensed to use.
- Export as JPG, ideally under 300 KB each.
- Images are cropped to fill the frame (`object-fit: cover`), so keep the subject centred.
- To use another format (e.g. `.webp`), update the paths in `index.html` (hero) and `js/data.js` (services).
